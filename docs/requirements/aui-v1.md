# AUI version 1: requirements

What the Admin UI must do to be complete for phase 1 (see the [roadmap](../roadmap.md)). AUI is a side interface with four modes by resizing (mini, small, medium, max); its meters are in the band under the header.

**Interview**: the phase 1 round is done (2026-11-26). The AUI round (the open questions below) comes before its mockup. AUI is built last in phase 1.

## Admin levels

The plan's levels map onto the roles that exist, and AUI names them so. Only the missing pieces are added.

| Level | Role |
|---|---|
| Site, System | the owner, and admins with site rights |
| Department | director |
| Team | manager |
| Support | channel support |
